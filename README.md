# SSG email signature banners

Publicly hosted banner images for Synthetic Sports Group, Synthetic Padel Group and True Blue Padel Courts email signatures.

Images are served via GitHub Pages:

`https://designbrandshake.github.io/SSG-email-signature-banners/images/<filename>`

## Usage in an email signature

```html
<a href="https://YOUR-LINK-HERE">
  <img src="https://designbrandshake.github.io/SSG-email-signature-banners/images/ssg-banner-1A-your.jpg"
       width="600" alt="Premium Synthetic Sports Surfacing Solutions for Schools, Clubs and Residential Projects" style="display:block;border:0;">
</a>
```

Keep filenames unchanged once in use. Renaming or deleting a file breaks every signature that links to it.
